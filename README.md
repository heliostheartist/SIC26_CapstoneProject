# SIC Capstone Project

## Cấu trúc

- `app.py`, `dropout_utils.py`: ứng dụng Streamlit và tiện ích dùng chung.
- `notebooks/`: quy trình phân tích và huấn luyện.
- `data/raw/`: dữ liệu đầu vào gốc.
- `models/artifacts/`: mô hình và metadata được notebook tạo.
- `Report_26_11_6.qmd`: nguồn báo cáo Quarto. `reports/` chứa hình, ảnh giao diện, logo và PDF bàn giao.
- `docs/`: đề cương, giải thích mã và rubric.
- `outputs/`: kết quả chấm điểm xuất ra.

## Chạy ứng dụng

Từ thư mục gốc dự án, cài các gói trong `requirements.txt`, sau đó chạy:

```bash
streamlit run app.py
```

Notebook tìm dữ liệu tại `data/raw/data.csv` và ghi hình/mô hình vào `reports/figures/` và `models/artifacts/`.
